# Sistema Bancário — Testes de Software com Java

##  Sobre o projeto

Este repositório reúne exercícios práticos desenvolvidos durante o curso de Testes de Software com Java.

O projeto **SistemaBancario** foi utilizado para praticar conceitos de programação Java e testes de software, com classes relacionadas ao gerenciamento de clientes e contas bancárias.

## Objetivos

* Praticar a linguagem Java.
* Desenvolver e organizar testes de software.
* Exercitar a validação de regras de negócio.
* Praticar a organização de código e classes de teste.

## Tecnologias e ferramentas

* **Java** — linguagem de programação.
* **Eclipse IDE** — ambiente de desenvolvimento.
* **JUnit** — framework de testes, caso confirmado na configuração do projeto.
* **GitHub** — versionamento e compartilhamento do código.

## Testes de software

O projeto contém classes de teste relacionadas ao gerenciamento de clientes e contas bancárias.

Os testes são utilizados para praticar a verificação do comportamento das classes e das regras de negócio implementadas.

## Como acessar o projeto

1. Clone ou baixe este repositório.
2. Importe o projeto no Eclipse como um projeto Java existente.
3. Confira as configurações de Java e as bibliotecas de teste necessárias.
4. Execute as classes de teste usando a configuração adequada do projeto.

As instruções específicas de execução podem ser complementadas após a confirmação da versão do Java e da configuração do JUnit.
